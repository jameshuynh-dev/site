Custom Discord bot · built for a client

Mimi Bot

  • Discord API
  • Twitch API

The problem

The client didn't want a public stream bot. They wanted their own private one, where they decide who's in the group and every member's go-live alert feels like theirs.

What Mimi does

  • Private to the client's server, and they add their own members to it
  • Every member gets their own embed color
  • A Watch on Twitch button sends viewers from Discord straight to the stream
  • When a stream ends, the alert updates itself with a timestamp of how long it lasted
